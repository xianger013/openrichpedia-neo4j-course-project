# 2. 环境安装与完整运行步骤

本章按“第一次接触数据库也能完成”的方式写。主路线是 **Python + Neo4j Desktop**。

## 2.1 安装软件

准备：

- Python 3.10 或更高版本；
- Git（可选，但推荐）；
- Neo4j Desktop；
- 一个文本编辑器，例如 VS Code。

本项目选择 Neo4j 5.26 LTS 作为稳定教学基线，Python Driver 使用 6.x。

## 2.2 获取本项目

如果仓库已经上传 GitHub：

```bash
git clone <你的仓库地址>
cd openrichpedia-neo4j-course-project
```

若使用本地压缩包，解压后进入项目根目录即可。

## 2.3 创建虚拟环境

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -e ".[dev]"
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -e ".[dev]"
```

## 2.4 先运行测试

```bash
pytest -q
```

测试全部通过说明 Python 侧环境正常。

## 2.5 下载固定版本 OpenRichpedia 数据

```bash
python scripts/fetch_openrichpedia.py
```

程序只下载课程项目实际需要的 6 个文件，并锁定上游提交，防止未来原仓库变化导致结果不可复现。

检查：

```text
data/raw/city.js
data/raw/city_sight.js
data/raw/pic_city.js
data/raw/contain.js
data/raw/people.js
data/raw/pic_people.js
```

如果某次下载中断，重新执行即可；已存在文件默认跳过。如需覆盖：

```bash
python scripts/fetch_openrichpedia.py --force
```

## 2.6 数据预处理

执行：

```bash
python scripts/preprocess.py
```

输出：

```text
data/processed/nodes.csv
data/processed/relationships.csv
data/processed/stats.json
```

随后独立验证：

```bash
python scripts/validate_processed.py
```

只有出现“验证通过”才继续导入 Neo4j。

## 2.7 创建 Neo4j 本地数据库

在 Neo4j Desktop 中：

1. 新建一个 Project；
2. 添加 Local DBMS；
3. 版本选择 5.26 LTS；
4. 设置一个你记得住的本地密码；
5. Start；
6. 打开 Query / Browser。

先执行：

```cypher
RETURN 'Neo4j is ready' AS message;
```

能返回字符串说明数据库可用。

## 2.8 自动导入（推荐）

### Windows PowerShell

```powershell
$env:NEO4J_URI="neo4j://localhost:7687"
$env:NEO4J_USER="neo4j"
$env:NEO4J_PASSWORD="你的密码"
python scripts/import_neo4j.py
```

### macOS / Linux

```bash
export NEO4J_URI=neo4j://localhost:7687
export NEO4J_USER=neo4j
export NEO4J_PASSWORD='你的密码'
python scripts/import_neo4j.py
```

成功后会打印实际导入的节点数和关系数。

## 2.9 验证 Neo4j 数据量

在 Neo4j Query 中执行：

```cypher
MATCH (n) RETURN count(n) AS node_count;
```

```cypher
MATCH ()-[r]->() RETURN count(r) AS relationship_count;
```

将结果与 `data/processed/stats.json` 对照，两边应一致。
